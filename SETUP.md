# Setup Instructions

This package is meant for the special GitHub profile repository named exactly:

```txt

```

GitHub shows the root `README.md` on your public profile when the repository name matches your username.

## Publish Steps

1. Create or open the public repository named `ChaitanyaJhindal`.
2. Copy these files into the repository root.
3. Review the contact and project links in `README.md` and change them only if you want a different public-facing version than the resume-aligned one.
4. If you publish a separate portfolio site or additional demos later, add those links where needed.
5. Push everything to the default branch, ideally `main`.

## Enable The Snake Workflow

1. Open the repository on GitHub.
2. Go to `Settings -> Actions -> General`.
3. Make sure Actions are enabled.
4. Under workflow permissions, choose `Read and write permissions`.
5. Save the setting.
6. Open the `Actions` tab.
7. Run the `Generate Contribution Snake` workflow once manually.
8. Wait for the workflow to create the `output` branch.

## After First Push

1. Pin your strongest repositories on your GitHub profile.
2. Add a short GitHub bio that matches the README tone.
3. Keep the `README.md` project cards aligned with your actual repos and live demos.
4. Refresh the profile page after the snake workflow completes.

## Optional Upgrades

1. Add a public repo link for the e-commerce customer support chatbot if you want that project card to point to a dedicated repository.
2. Add more live demo links as your public project surface grows.
3. Add GitHub profile trophies or a custom metrics pipeline if you want even more dashboard depth.
